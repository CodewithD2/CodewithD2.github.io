# كروتي — ملفات المصدر

- `cards.json`: كل الجمل. كل جملة فيها `e` (الإيموجي)، و`en` (الإنجليزي)، و`pr` (النطق بحروف عربي)، و`ar` (المعنى). وممكن يكون فيها كمان `re` (ردود جاهزة).
- `app.html`: كود التطبيق.
- `build.js`: بيبني فولدر `travel/` اللي بيتنشر على GitHub Pages.

## إزاي تضيف جمل

1. عدّل `cards.json`.
2. شغّل `node travel-src/build.js` (محتاج Node.js).
3. اعمل commit وpush على `main`.
4. على الموبايل، دوس **🔄 حمّلي آخر تحديث**، والجمل الجديدة هتظهر وعليها علامة «🆕 جديد».

> لو عدّلت `cards.json` من غير ما تشغّل `build.js`، التطبيق مش هيتغيّر.
