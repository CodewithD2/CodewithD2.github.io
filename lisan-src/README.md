# لسان — ملفات المصدر

- `data/es.json` و`data/ru.json`: محتوى كل لغة، وفيه:
  - `abc`: الحروف والأصوات.
  - `phrases`: الجمل اليومية.
  - `topics`: قواميس المجالات المتخصصة (الفيزياء، الكيمياء، علوم الحاسب، الطبخ، المحاسبة، المال والاقتصاد، السياسة، الفنون والأدب، الطب).
  - `quotes`: اقتباسات من الروايات والكتب المشهورة، وكل اقتباس فيه `v` لمعاني كل كلماته.
  - `artPhrases`: عبارات جاهزة لوصف أي لوحة فنية.
  - `texts`: النصوص (قصص، خطابات، أخبار، أدب مشهور، ووصف لوحات فنية `art`). كل نص فيه `s` (الجمل وترجمتها) و`v` (معنى كل كلمة في النص).
  - `me`: قوالب «عرّف نفسك».
- `app.html`: كود التطبيق.
- `build.js`: بيبني فولدر `lisan/` اللي بيتنشر على GitHub Pages. وبيرفض يبني لو فيه كلمة في نص ملهاش معنى في `v`.

## إزاي تضيف نص أو لغة

1. عشان تضيف نص: زوّده في `texts` في ملف اللغة.
2. عشان تضيف لغة: اعمل ملف جديد في `data/` بنفس الشكل (مثلاً `fr.json`).
3. شغّل `node lisan-src/build.js`، وبعدين ارفع على `main`.
4. في التطبيق، دوس **🔄 حمّل آخر تحديث**.
